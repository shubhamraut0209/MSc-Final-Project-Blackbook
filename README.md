# MSc Final Year Project – Service Quality & Customer Loyalty Analysis

## 📌 Project Title
**Statistical Measurement of Service Quality of Indian Domestic Airlines**

## 📖 Overview
This project was conducted as part of my MSc in Statistics at K.C. College, HSNC University. The aim was to analyze the relationship between key demographic variables and customer loyalty, service quality dimensions, and passenger emotions across Indian domestic airlines.

## 🎯 Objectives
- Identify significant demographic factors influencing customer loyalty
- Analyze passenger perception of service quality
- Measure emotional response to service experiences
- Recommend strategies for airline companies to improve service quality

## 🛠️ Tools & Techniques Used
- **SPSS & SPSS Amos** – For data cleaning, loglinear analysis, and model fitting
- **R Programming** – For statistical modeling and visualizations
- **Microsoft Excel** – For primary data entry and initial exploration
- **Machine Learning** – Decision Tree Analysis, Logistic Regression
- **Survey Data** – Primary data collected via structured questionnaires

## 📊 Key Techniques Applied
- Loglinear Analysis  
- Cluster Analysis  
- Logistic Regression  
- Sentiment Analysis  
- Decision Tree Analysis
